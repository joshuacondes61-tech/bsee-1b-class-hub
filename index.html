💾 Backup your data

Export announcements, schedules, reminders, and material metadata as a JSON backup. Uploaded files stored in this browser are included as data URLs and can make the backup large.

🌐 About sharing

This starter website stores data in this browser using local storage. Other classmates using a different phone or browser will not automatically see uploads or changes. For a genuinely shared class hub, connect a cloud database and file storage, then publish the site.

Tip: Keep a backup regularly, and share only learning materials you have permission to distribute.

🧹 Clear local data

This removes this browser’s stored class hub data. Export a backup first if you want to keep it.
